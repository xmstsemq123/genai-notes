## 上課時的想法

- 以前以為跑本地模型就是看參數量，原來要看 VRAM。4-bit 量化大概是參數量（B）乘 0.5 再加 1 到 2 GB，20B 的 gpt-oss 要 10 GB 以上。實驗室的 4090 是 24GB，跑 20B 應該可以。
- Mac 的 unified memory 那段很有趣，記憶體多大差不多就是 VRAM 多大。但老師說頻寬會影響生成速度，所以不是容量夠就好。
- Karpathy 說幻覺是 LLM 最大的特點，不是 bug。我的理解是 LLM 本來就是在「生」東西，我們不想要的其實是「助理」亂講。
- 老師最後一句「一定要讀它寫了什麼」我覺得是整堂課最重要的。沒寫錯不代表寫對我的意思。
- system prompt 就是人設。員瑛式思考那個例子只是在 system 裡多寫幾句，效果就差很多。

## 作業做了什麼

- HW06 我做的是「口試前五分鐘」，研究生口試陪練機器人。保留老師 AISuite + Gradio 的架構。
- 規則：第一次只問一題，回答後固定用「有說清楚的地方」「還缺的依據」各一句，再問下一題。不能幫我編數據或文獻，也不能假裝是真的教授。
- 有「陪練」「提示」「整理」三個按鈕。提示跟整理不能偷偷換題，所以我用 Python 記住目前的題目。
- 跟 AI 討論了三輪才把人設定下來。第一版 AI 說每次只問一題，結果示範裡一次問兩題，這是我自己讀出來的問題。
